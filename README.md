Includes merged fullscreen subtitles, durable browser exit, WOL prompt scaling and tooltip metrics, plus radar subtitles through the tactical HUD. Retains directory/ZIP/HTTPS import, atomic resource caching, backups, durable user data, viewport sizing and the fork YR-style default (explicit saved opt-outs win). No unvalidated Logo/F11 changes are included. Only the current version is served; no retail resources, translation pack, private tests or local paths are distributed.

This build passed 39 import/launcher tests, six startup checks and 24 subtitle logic checks. An isolated muted browser using local Chinese resources displayed the first Allied mission's loading art/progress, fullscreen movie subtitles, radar video and HUD cue. Mission restart and communication retirement were observed; a timed mid-clip pause/resume observation was interrupted and remains unverified. Full campaign completion, native pixel equivalence, remote multiplayer and audio listening are not claimed. Manual browser tabs can refuse scripted close and retain the saved-exit message. No existing player page or saved data was changed.
